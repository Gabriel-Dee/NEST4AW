# Frontend instructions

Epic Cure MTG warehouse UI. Next.js App Router in `frontend/`. The API contract is `docs/API.md`. The aisle phone is `../mobile/`.

`AGENTS.md` is regenerated by Next.js. Keep project conventions here.

## Tech stack

- Next.js 16.4, React 19, TypeScript 5, Tailwind CSS 4, shadcn/ui (base-nova), Lucide
- Dev and production both use port **5173** (`npm run dev`, `npm run start`)
- Lint: `npm run lint`. No test runner is configured.
- Data today is the in-memory mock in `src/lib/mock/api.ts`. Do not call the backend until that mock is replaced. Verdict colors come only from the `verdict` field (`green` | `yellow` | `red` | `unknown`).

## Roles

Five role strings exist on `Role` in `src/lib/types.ts`. The UI serves four of them.

| Role | Login | Home | Nav |
| --- | --- | --- | --- |
| `warehouse_staff` | `staff@demo.local` | `/checkout` | Checkout, Warehouse, Kiosk |
| `doctor` | `doctor@demo.local` | `/admin/clinical` | Clinical intake, Analytics, Rules, Kiosk |
| `admin` | `admin@demo.local` | `/admin` | All staff links |
| `community_partner` | `partner@demo.local` | `/admin/analytics` | Analytics only |
| `client` | none | falls through to `/kiosk` | none |

Password for the four demo accounts: `nest-local-demo`. Auth is `sessionStorage` (`epic-cure-auth`), not a JWT.

`/kiosk` is public card check-in. It is not a role. `client` has no `/me` screens yet.

Nav filtering lives in `src/components/layout/app-shell.tsx`. Pages do not re-check the role. The sidebar **Switch role** control rewrites the stored role for demo and is not an API call.

## Code style

- Routes and files: kebab-case (`app-shell.tsx`, `verdict-badge.tsx`). Components: PascalCase. Helpers: camelCase.
- Pages are client components. Shared chrome is `AppShell` in `src/app/layout.tsx`.
- Path alias `@/` → `src/`. UI primitives stay in `src/components/ui/`.
- Errors from the mock are thrown `Error`s (login) or errors with a `status` (arrive). Surface the server message; do not invent verdicts.

## Project structure

```
src/app/            routes (login, kiosk, checkout, warehouse, admin/*)
src/components/ui/  shadcn primitives
src/components/layout/  shell and role nav
src/components/status/  verdict badge
src/lib/auth.tsx    session auth context
src/lib/types.ts    Role, Verdict, domain types
src/lib/mock/       catalog, clients, rules, fake API
```

## Conventions

- Commit messages on `main` are imperative sentences (`Add the admin analytics…`).
- Work for this package stays on a `frontend` branch when branching. Keep `docs/API.md` in the same change if a route changes.
- Partner-facing data stays anonymized: day, tier, grant, units, pounds. No client names on analytics.
